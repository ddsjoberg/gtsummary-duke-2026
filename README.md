## Description

{gtsummary} is the most widely used R package for creating presentation-ready
summary tables across the R ecosystem. It provides an elegant and flexible way
to summarize data sets, regression models, and more, with sensible defaults and
a high degree of customization.

In this seminar, we will introduce {gtsummary} and walk through how it fits
into a reproducible reporting workflow. Topics include:

- **{gtsummary} fundamentals:** Creating demographic and summary tables with
  `tbl_summary()`, adding statistics, p-values, and overall columns, and
  customizing labels and formatting.
- **Combining and extending tables:** Hierarchical summaries, merging and
  stacking tables, and choosing a print engine to export to HTML, Word, PDF,
  and more.
- **Analysis Results Data (ARD):** How {gtsummary} and ARDs work together by
  design, so the numbers in your tables are traceable and reusable.
